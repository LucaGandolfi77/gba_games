# game02 — HelloWorld GBA

Semplice progetto HelloWorld per Game Boy Advance usando libgba.

Prerequisiti:
- devkitPro con `devkitARM` e `libgba` installati (usare `dkp-pacman -S devkitARM libgba`)

Compilare:

```bash
cd game02
make
```

Output: `game02.gba` pronto per essere eseguito in un emulatore (mGBA) o flashato.
